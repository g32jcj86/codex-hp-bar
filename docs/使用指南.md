# Codex HP Bar 詳細使用指南

## 下載與免安裝啟用

1. 開啟 GitHub 儲存庫的 **Releases** 頁面。
2. 下載名稱包含 `win-x64-portable.zip` 的檔案。
3. 核對 SHA-256 後解壓縮。
4. 雙擊 `CodexHpBar.exe`。

程式為 self-contained single-file 可攜版，目標電腦不需要另外安裝 .NET。執行階段可能將必要的原生元件暫時展開至使用者暫存目錄，這不等同安裝。

## 首次啟用

啟動後自動在背景待命並加入 Windows 登入自動啟動，無需設定，不會顯示設定視窗。

### 背景待命

即使 Codex 關閉，監測器仍在背景等待。此時工具列不會顯示儀表，也不會持續查詢額度。再次開啟 Codex 後，儀表會自動出現。

在任一螢幕的儀表按滑鼠右鍵，會顯示「立即更新」與「關閉監測器」。選擇「關閉監測器」後，所有儀表及背景程序都會一起結束。

### Windows 登入自動啟動

每次正常啟動，程式會在目前使用者 Startup 資料夾建立或修復捷徑。它不寫入系統登錄檔，也不需要系統管理員權限。

程式關閉後，可用 `CodexHpBar.exe --reset-settings` 清除設定與 Startup 捷徑，清除後即結束。下次正常啟動會重新建立預設設定與捷徑。

## 多螢幕與工具列

程式會列舉主工具列與副工具列，每個工具列各顯示相同額度。主螢幕儀表放在系統匣左側；沒有可辨識系統匣的副螢幕會在右側保留 120 DIP 的時鐘與狀態區安全寬度，避免遮住日期、時間及輸入法資訊。

顯示器 DPI、解析度或 Explorer 工具列重建後，位置會重新計算。工具列自動隱藏或全螢幕應用程式遮蔽工具列時，儀表同步隱藏。

## 額度更新

啟動後立即讀取一次額度，之後接收 app-server 更新通知，並每 15 秒重新同步。更新失敗時：

1. 五分鐘內保留最後成功資料並顯示黃色圓點。
2. 超過五分鐘改顯示 `--%`。
3. 程式持續重試，不需要重新登入時不會打開瀏覽器。

## 更新可攜版

1. 結束舊版 Codex HP Bar。
2. 下載並核對新版 Release。
3. 將新版放入新的資料夾並執行。
4. 新版啟動後會自動修復 Startup 捷徑，使其指向新版 EXE。

設定儲存在 `%LOCALAPPDATA%\CodexHpBar`，更換 EXE 不會自動清除偏好。
