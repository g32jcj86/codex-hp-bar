# Codex HP Bar 詳細使用指南

## 下載與免安裝啟用

1. 開啟 GitHub 儲存庫的 **Releases** 頁面。
2. 下載名稱包含 `win-x64-portable.zip` 的檔案。
3. 核對 SHA-256 後解壓縮。
4. 雙擊 `CodexHpBar.exe`。

程式為 self-contained single-file 可攜版，目標電腦不需要另外安裝 .NET。執行階段可能將必要的原生元件暫時展開至使用者暫存目錄，這不等同安裝。

## 首次啟用

首次執行會顯示設定視窗，兩個選項預設都未勾選。

### 背景待命

啟用後，即使 Codex 關閉，監測器仍在背景等待。此時工具列不會顯示血條，也不會持續查詢額度。再次開啟 Codex 後，血條會自動出現。

未啟用時，監測器在 Codex 關閉後直接結束。下次使用需要再次手動執行 EXE。

在任一螢幕的血條區塊按滑鼠右鍵，會顯示「立即更新」、「設定」與「關閉監測器」。選擇「關閉監測器」後，所有血條及背景程序都會一起結束。

### Windows 登入自動啟動

啟用後，程式在目前使用者 Startup 資料夾建立捷徑。它不寫入系統登錄檔，也不需要系統管理員權限。自動啟動依賴背景待命，因此勾選時會一併勾選背景待命。

## 更換角色圖片

在任一血條按右鍵選擇「設定」，即可更換工具列上的角色圖片；套用後所有螢幕立即使用新設定。

### 圖片模式

- **內建菇菇寶貝**：使用程式內建的透明 PNG，適合第一次使用。
- **靜態圖片**：使用 PNG、JPG、BMP 或 ICO，固定顯示單張圖片。
- **GIF 動圖**：使用 GIF 內建的每格延遲循環播放；程式會先將局部影格恢復到共同畫布，再等比例顯示，避免動畫中角色忽胖忽瘦；單格 GIF 會當作靜態圖片。
- **4×4 連續動畫圖片**：使用一張包含 16 格的圖片，程式會在載入時切割成 4 欄×4 列。

### 4×4 動畫規則

請依照遊戲常見的 sprite sheet 格式製作：

1. 圖片必須能平均切成 4 欄與 4 列，不能有邊界留白、格間距或不等寬影格。
2. 影格尺寸完全相同，編號順序為左至右、上至下（第 0 列的 0–3 格，再到第 1 列）。
3. 播放第 15 格後回到第 0 格，不使用來回反彈；播放速度可設定 1–30 FPS，預設 8 FPS。
4. 建議使用帶透明背景的 PNG；檔案上限為 20 MB，圖片最長邊不可超過 4096 像素。
5. 透明 PNG 會依各格可見像素的共同底線自動對齊；JPG 或不透明底圖無法判斷角色底線，建議改用透明 PNG。

GIF 使用檔案內建速度，4×4 圖片使用設定的 FPS；4×4 模式不會額外套用週期性上下浮動，透明影格只會套用固定底線對齊。Windows 的「視覺效果」停用動畫時，程式會暫停影格播放但仍保留圖片。

選擇外部圖片後，程式會先複製到執行檔旁的 `MascotAssets` 資料夾，設定檔位於 `%LOCALAPPDATA%\CodexHpBar\settings.json` 並記錄複製後的路徑；原始檔案不會被刪除，也不會上傳或執行圖片內容。更新或搬移程式時請一起保留 `MascotAssets` 資料夾。

## 多螢幕與工具列

程式會列舉主工具列與副工具列，每個工具列各顯示相同額度。主螢幕血條放在系統匣左側；沒有可辨識系統匣的副螢幕會在右側保留 120 DIP 的時鐘與狀態區安全寬度，避免遮住日期、時間及輸入法資訊。

顯示器 DPI、解析度或 Explorer 工具列重建後，位置會重新計算。工具列自動隱藏或全螢幕應用程式遮蔽工具列時，血條同步隱藏。

## 額度更新

啟動後立即讀取一次額度，之後接收 app-server 更新通知，並每 15 秒重新同步。更新失敗時：

1. 五分鐘內保留最後成功資料並顯示黃色圓點。
2. 超過五分鐘改顯示 `--%`。
3. 程式持續重試，不需要重新登入時不會打開瀏覽器。

## 更新可攜版

1. 結束舊版 Codex HP Bar。
2. 下載並核對新版 Release。
3. 將新版放入新的資料夾並執行。
4. 若曾啟用開機啟動，開啟設定並重新套用，修復指向新版 EXE 的捷徑。

設定儲存在 `%LOCALAPPDATA%\CodexHpBar`，更換 EXE 不會自動清除偏好。
