# 疑難排解

## 血條沒有出現

可能原因：Codex 桌面應用程式未執行、監測器已退出，或工具列正在自動隱藏。

1. 確認 Codex Windows 桌面應用程式已開啟。
2. 再次執行 `CodexHpBar.exe`。
3. 執行 `.\CodexHpBar.exe --self-test`，確認結束碼為 `0`。

## 顯示 `--%`

將滑鼠停在血條上查看錯誤。常見原因是找不到 Codex app-server、Codex 尚未登入，或網路暫時無法連線。

1. 在 Codex 桌面應用程式確認已登入。
2. 關閉並重新開啟 Codex。
3. 在血條右鍵選擇「立即更新」。

## 數值沒有立即改變

程式接收通知並每 15 秒同步。Codex 後端也可能延遲更新額度；等待 15 秒後再選擇「立即更新」。

## 開機後沒有啟動

可攜版被移動或刪除時，Startup 捷徑會失效。手動執行目前位置的 EXE，開啟設定，取消再重新勾選開機啟動。

## SmartScreen 顯示未知發行者

本專案沒有商業程式碼簽章。請確認檔案來自 `g32jcj86/codex-hp-bar` Release，並核對 `SHA256SUMS.txt`。不要從第三方重新封裝網站下載。

## 多螢幕位置不正確

重新啟動 Explorer 或登出再登入 Windows。若仍發生問題，回報各螢幕解析度、縮放比例與工作列位置，但不要附上未裁切桌面截圖。

## 效能異常

正常狀態下兩個工具列視窗平均 CPU 應低於 1%。請先確認沒有重複執行；程式內建單一執行個體鎖。回報時請附工作管理員中的 CPU、記憶體與程式版本，不要附登入資料。
