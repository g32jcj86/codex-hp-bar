# v0.2.1 驗證摘要

本版本新增菇菇寶貝素材與可切換圖片播放器；以下是本次變更的自動化驗證重點。

## 本次自動化結果

- `dotnet format CodexHpBar.slnx --verify-no-changes --no-restore`：通過。
- `dotnet build CodexHpBar.slnx -c Release --no-restore`：零警告、零錯誤。
- `dotnet test tests\CodexHpBar.Tests\CodexHpBar.Tests.csproj -c Release --no-restore`：23 項全數通過。
- 設定相容性測試涵蓋舊版設定補上內建圖片、FPS 邊界與內建圖片清除外部路徑。
- 4×4 圖片播放器限制為 16 個等尺寸影格，採逐列、循環播放，並限制 1–30 FPS。
- 外部圖片限制為本機檔案、20 MB 與 4096×4096 像素；套用前會複製到執行檔旁的 `MascotAssets` 資料夾，不執行圖片內容。
- Markdown 相對連結、圖片與繁體中文用詞檢查：通過。

## 本次素材覆核

- 菇菇寶貝 PNG 以透明背景嵌入 WPF 資源，工具列繪製維持 nearest-neighbor 縮放。
- 設定視窗支援內建圖片、靜態圖片、GIF 與 4×4 sprite sheet，套用後同步更新所有工具列視窗。
- GIF 使用檔案影格延遲；4×4 圖片依左至右、上至下順序以設定 FPS 循環播放。
- 4×4 模式不額外套用上下浮動，垂直移動完全由 sprite sheet 影格控制。
